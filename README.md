# C Programming Practice Repository
This repository contains fundamental and intermediate C programming problems including:
- Basic I/O
- Arithmetic operations
- Conditional operators
- Prime optimization using sqrt(n)
- Overflow-safe integer reverse
- Recursive and iterative Fibonacci
- Factorial computation
- Function pointers
- String manipulation
- Safe string copy (buffer overflow prevention)
Each program is implemented in a separate .c file for modular learning.
